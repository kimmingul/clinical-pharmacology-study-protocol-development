Claude Code Plugin · v4.2.0

임상약리 임상시험 계획서 개발을, 조사부터 검증까지 한 흐름으로.

FIH, DDI, BE/FE, QTc, ADME 연구 문서를 8개 전문 에이전트와 10단계 파이프라인으로 작성하고 검토합니다.

v4.2.0 다운로드 GitHub에서 보기

AI 생성물은 전문가 검토와 IRB 승인이 필요한 초안입니다. 실제 연구 시작, 규제 제출, 시험대상자 배포 전에는 의학·통계·규제 전문가의 검증이 필요합니다.

Protocol pipeline
ICH E6(R3)
  1. 1 자료 조사문헌, 라벨, ClinicalTrials.gov, MFDS/FDA/EMA 근거 수집 /research
  2. 2 설계 결정선정·제외기준, 평가변수, 통계 설계, sample size /design
  3. 3 Synopsis 작성승인된 설계를 기준으로 핵심 시험 개요 생성 /synopsis
  4. 4 Protocol 작성ICH E6(R3) Appendix B 16개 섹션 구조 반영 /protocol
  5. 5 다중 검토전문가 페르소나와 결정적 도구로 critical issue 수렴 /review

임상약리 문서 개발에 필요한 역할을 한 플러그인에 담았습니다.

조사, 설계, 작성, 검토가 끊어지지 않도록 각 단계의 입력과 산출물을 명확히 연결합니다.

8개 전문 에이전트.

clinical pharmacologist, translational scientist, regulatory expert, clinician, biostatistician, writer, reviewer 역할을 분리해 문서 품질을 높입니다.

10단계 파이프라인.

자료 조사부터 Synopsis 승인, Full Protocol, 다중 리뷰, ICF 생성까지 사용자 검토 게이트를 포함한 순서로 진행합니다.

ICH E6(R3) 기반.

Appendix B 16개 공식 섹션 구조와 KGCP 보존기간, MFDS/FDA/EMA 가이드라인을 문서 작성 기준으로 사용합니다.

시험 유형별 설계.

FIH/SAD/MAD, DDI 단방향·양방향, BE, FE, QTc, ADME, 특수 집단 PK 연구에 맞춘 설계 흐름과 sample size 스크립트를 제공합니다.

Multi-LLM 검토.

v4 계열은 보유한 Claude, GPT, Gemini, Grok CLI를 capability 기반으로 라우팅해 cross-vendor critic 패널을 구성할 수 있습니다.

근거 중심 산출물.

PMID, NCT, URL, 라벨, 가이드라인 인용을 요구하고 citation audit과 source snapshot으로 재현성을 보강합니다.

명령은 짧고, 산출물 흐름은 명확합니다.

각 명령은 이전 단계의 승인된 산출물을 입력으로 사용해 설계 결정이 하류 문서에서 흔들리지 않도록 합니다.

기본 실행 순서

프로젝트 디렉토리에서 Claude Code를 열고 아래 명령을 순서대로 실행합니다.

  • /research자료 조사
  • /design연구 설계
  • /synopsisSynopsis 작성
  • /protocolFull Protocol 작성
  • /review다중 검토
  • /finalize최종 가드레일
  • /icf동의문서 작성

지원하는 연구 유형

허가 약물의 공개 자료 기반 연구부터 IB가 필요한 FIH 연구까지 임상약리 Phase 1 문서 개발 흐름을 다룹니다.

FIH / SAD / MAD DDI one-sequence DDI 2x2 crossover Williams 6x3 DDI BE / RSABE Food Effect QTc ADME Special Population PK

초안 생성보다 중요한 것은, 검증 가능한 초안입니다.

  • Zero-trust citation PubMed, ClinicalTrials.gov, DailyMed, URL 인용을 독립 재조회하고 audit JSON으로 남깁니다.
  • Fail-closed egress 기밀 IB와 안전 핵심 정보는 외부 LLM 전송을 기본 차단하고, 공개 규제 자료만 명시적으로 허용합니다.
  • Dose safety guard FIH 시작 용량과 증량 용량이 MRSD 근거를 벗어나지 않는지 결정적 검사로 확인합니다.
  • Actor-critic review loop Critical issue 0건과 문서 점수 기준을 만족할 때까지 검토와 수정 계획을 반복합니다.

Claude Code 플러그인으로 설치합니다.

GitHub 저장소를 marketplace로 등록한 뒤 플러그인을 설치하면 명령, 에이전트, 스킬이 함께 로드됩니다.

# 1) GitHub 저장소를 marketplace로 등록
/plugin marketplace add kimmingul/clinical-pharmacology-study-protocol-development

# 2) 플러그인 설치
/plugin install clinical-pharmacology-study-protocol-development

# 3) 명령과 에이전트 로드 확인
/plugin

필수 환경

Claude Code 최신 버전, Python 3.10 이상, sample size 계산용 scipy, 그리고 PubMed·ClinicalTrials.gov·DailyMed·openFDA·MFDS 자료 접근이 가능한 네트워크 환경이 필요합니다.
